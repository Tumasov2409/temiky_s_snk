# ⚡ DotaRadar PRO — Мульти-маркет сканер и мониторинг ликвидности Dota 2

Веб-приложение для мгновенного поиска недооцененных предметов, TB Аркан с редкими самоцветами, курьеров Onibi со стилями и арбитража цен между крупнейшими торговыми площадками (**Steam Community Market, Market.Dota2, Buff163, DMarket**).

---

## 🚀 Как выложить на GitHub и запустить за 1 минуту

Проект не требует установки Node.js, сборщиков и зависимостей. Он работает прямо в браузере и идеально подходит для бесплатного хостинга на **GitHub Pages**:

### Вариант через сайт GitHub (без консоли):
1. Создайте новый репозиторий на [GitHub.com](https://github.com/new) (например, с названием `dota-radar`).
2. Перетащите файлы из папки `Трейд` (`index.html`, `styles.css`, `app.js`, `README.md`) прямо в окно репозитория на GitHub и нажмите **Commit changes**.
3. В репозитории откройте вкладку **Settings** ➔ слева раздел **Pages**.
4. В пункте **Branch** выберите `main` (или `master`) и папку `/ (root)`, затем нажмите **Save**.
5. Через 30 секунд ваш сайт будет доступен по адресу:
   `https://ваш-логин.github.io/dota-radar/`

## 💎 Главные фичи сайта

1. **Мгновенный поиск предметов и самоцветов:**
   * Введите, например: `TB Creator's Light`, `Onibi 20`, `Sea Green`, `Manifold Paradox`, `TF2 Key`.
   * Система автоматически определяет цвет гема, рассчитывает справедливую стоимость и генерирует **готовые прямые ссылки** на все площадки.
2. **Точные фильтры для Steam Торговой площадки:**
   * Ссылки на Steam автоматически содержат нужные поисковые параметры (например, фильтр по гнездам `Prismatic: Creator's Light` или для Onibi `NOT "Upgrade Style 20 (Locked)"`), что экономит массу времени при поиске.
3. **Матрица гемов для Fractal Horns of Inner Abysm (TB):**
   * Таблица всех популярных призматических гемов с HEX-цветами, редкостью, отдельной стоимостью гема и формулой справедливой цены арканы с этим гемом.
4. **Топ самых ликвидных предметов (Валюта трейда):**
   * Быстрый доступ к вещам с максимальным суточным объемом, которые легче всего конвертировать в реальные деньги.
5. **Калькулятор окупаемости и арбитража:**
   * Расчет чистой прибыли с учетом комиссий: Steam (13.04%), Market.Dota2 (5%), Buff163 (2.5%) и налога на вывод средств в реал (СБП/карты).
6. **Мультивалютность:**
   * Переключение между **₽ (RUB)**, **$ (USD)**, **€ (EUR)** и **¥ (CNY)** в один клик.
